# Icône PWA — Rapport journalier AINM

```sh
cd ~/projets
unzip -o ~/storage/downloads/rapport-journalier-ainm-pwa-v9.6-beta-icone-pwa.zip
cd ~/projets/rapport-journalier-ainm-pwa
git add -A
git commit -m "Mise à jour icône PWA AINM"
git push
```

L’icône Android est remplacée par le logo Rapport journalier AINM (rapport validé et rails).

Avant de supprimer une ancienne installation PWA, exporter toute saisie non archivée avec **Sauvegarder la saisie**. La suppression d’une application installée peut effacer son brouillon local.

Après publication, ouvrir le site dans Chrome, supprimer l’ancienne installation si son icône ne se met pas à jour, puis choisir **Installer l’application** ou **Ajouter à l’écran d’accueil** dans le menu Chrome.
