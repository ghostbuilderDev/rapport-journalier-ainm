```sh
cd ~/projets
unzip -o ~/storage/downloads/rapport-journalier-ainm-pwa-v8.5-tableaux-entreprises-logo.zip
cd ~/projets/rapport-journalier-ainm-pwa
git add -A
git commit -m "Mise à jour V8.5 : tableaux entreprises et logo"
git push
```

Attendre une à deux minutes, fermer complètement l’application AINM, puis la rouvrir depuis son icône. Si l’ancien logo reste affiché, ouvrir une fois le lien GitHub Pages dans Chrome puis relancer l’application.
